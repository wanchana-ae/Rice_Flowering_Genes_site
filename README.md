# Rice_Flowering_Genes_site

Results of the flowering-time / photoperiod gene analysis in rice (snpEff, flowering date and photosensitivity by SNP genotype,
accession groups from each gene's SNPs, and gene trees). GitHub Pages site: https://wanchana-ae.github.io/Rice_Flowering_Genes_site/

- `index.html` — results page
- `tree-viewer.html` — interactive gene-tree viewer (D3, self-contained)
- `data/` — figures (violin plots, group summary) and TSV tables used by the pages

Generated from `01 Projects/Rice_Flowering_Genes` (scripts 10 and 11).
